# BlackHeartOrder V2.0.1 正式串接版

## 已完成
- 線上點餐每 10 秒讀取 POS Apps Script 的 `order_status`。
- 同步地瓜球、飲料、餐點接單狀態。
- 同步等待時間與今日公告。
- 進入結帳及送單前強制重新讀取一次。
- Apps Script 暫時連不到時保留最後一次成功狀態。
- 前台不含 POS 寫入密鑰。

## 部署順序
1. 將 POS 專案內 `AppsScript/POS/Code.gs` 覆蓋目前 Apps Script。
2. Apps Script「管理部署作業」建立新版本，執行身分選擇自己，存取權限維持原設定。
3. 將本資料夾所有檔案覆蓋線上點餐網站。
4. POS 設定內的 Web App 網址必須指向同一個 Apps Script `/exec`。
5. POS 的 API 密鑰仍只用於寫入；線上點餐讀取狀態不需要密鑰。

## 測試
- POS 開啟「🌐 線上接單」，把飲料改為停止並按「儲存並同步」。
- 10 秒內線上點餐的飲料應變成停止接單。
- 修改等待時間與公告後再次同步，首頁應一起更新。
