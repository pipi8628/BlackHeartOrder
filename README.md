# BlackHeartOrder V1.2

可直接部署到 GitHub Pages 的前端測試版。

## 已完成
- 讀取 POS 匯出的 products.json
- 自動隱藏「老闆招待」與「隱藏版」
- 地瓜球整合為單一商品
- 最多選兩種口味，價格取最高價
- 飲料尺寸／甜度／冰量／加料
- 購物車增減、刪除、編輯
- 購物車自動保留在瀏覽器
- 取餐姓名、電話、時間與備註
- 建立並複製測試訂單內容

## 尚未完成

- 訂單 API
- POS 自動接單與列印
